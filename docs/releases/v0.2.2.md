# Easy Apply Automaton v0.2.2

The Windows desktop now includes the completed GUI improvements shown in the
README, alongside the same CLI and 21-topic offline tutorial.

- Live Apply, Scan, Reapply and Connect counters, target progress and elapsed
  time. Confirmed applications/messages stay separate from drafts, invitations,
  completed dry runs and uncertain submissions.
- Compact, naturally wrapped logs with colored severity/activity labels.
  **Details** restores the original diagnostic prefixes.
- Two-line hover help across desktop fields, toggles, labels and choices:
  purpose first, then a practical example.
- A fixed essential toolbar: right-clicking Tutorial no longer offers the
  accidental **Main** hide checkbox. Normal field-editing menus remain.
- A shorter README with the updated walkthrough GIF and selected screenshots.
  Media use fictional offline examples, not live application evidence.

## Download and upgrade

Download `EasyApplyAutomaton-0.2.2-windows-x64.zip`, verify `SHA256SUMS`, and
extract the entire folder into a new version directory. Keep `lea.exe` and
`_internal` beside `EasyApplyAutomaton.exe`. Finish active commands and save
editor changes before reopening; do not overwrite or restart a running app.

Existing workspace files and settings are retained. Set `LEA_WORKSPACE` to an
already configured workspace rather than initializing it again. An existing
`private-setup\Start-SourceSetup.cmd` still runs the source checkout directly;
it does not download or choose a release. Keep using that same command after
updating the source if you need the source environment and its optional extras.

Python is bundled; installed Edge/Chrome is required. The unsigned portable
package excludes browser binaries, Streamlit and OpenAI. Dynamic resumes need
the separate builder and an explicit external Python interpreter.

The manifest records the exact source commit and every bundled file hash.
Offline qualification does not imply fresh-machine, live LinkedIn or human
visual acceptance. Older release assets and private inputs are not replaced.
