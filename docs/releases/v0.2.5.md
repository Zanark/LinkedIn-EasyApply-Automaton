# Easy Apply Automaton v0.2.5

## Desktop and invitation fixes

- All 36 action icons now render at 64-by-64 logical pixels, up from 40-by-40.
  The action tile stays 112 by 108 pixels with its full centered labels.
- **Reapply > List retry targets only** keeps the action tile and five numeric
  cards: Targets, Failed, Aborted, Attempts and Repeated. These describe the
  selected saved batch, not new applications, failures or messages. No browser
  opens. Live Reapply retains application and hiring-team outcome counters.
- The optional **Connect without a note if unavailable** fallback now waits for
  usable controls and recognizes explicit note-free actions or Send/Connect
  inside an identified invitation dialog. Notes remain preferred; unrelated
  composers, conflicting drafts and arbitrary send errors do not permit a plain
  retry. Delivery needs profile Pending or a new invitation-sent confirmation,
  not merely a click or modal closure. Dry run sends nothing.

The README is shorter and branded, with detailed guidance moved into linked
guides. Documentation, media, tests and build tools are grouped by purpose;
the application entry points and private workspace paths are unchanged.

## Parallel release qualification

Ten test lanes cover five suites on Python 3.12 and 3.13, each using two
isolated workers. Style, types and the frozen Windows build/smoke run
independently. Every lane must succeed before a tag can publish; missing,
failed, cancelled or skipped results block publication. Each test lane retains
JUnit and coverage reports.

New regressions exercise relocated schema, tutorial and public configuration
resources from an unrelated working directory, public documentation links,
build roots with spaces, archive hashes/manifests, excluded private payloads
and fail-closed workflow behavior. Invitation browser fixtures are required.
Fictional offline checks do not establish current live LinkedIn behavior,
fresh-machine compatibility or human visual acceptance.

## Download and upgrade

Download `EasyApplyAutomaton-0.2.5-windows-x64.zip`, verify `SHA256SUMS`, and
extract the **entire folder into a new version directory**. Keep `lea.exe` and
`_internal` beside `EasyApplyAutomaton.exe`. Finish active commands and save
unsaved edits before deliberately opening the new version. Do not overwrite
or restart a running application.

To reuse a configured workspace, set `LEA_WORKSPACE` to its existing folder;
do not initialize it again. The source launcher still runs its own checkout,
not the downloaded EXE. No automatic installation or workspace migration occurs.

Python is bundled; installed Edge/Chrome is required. The unsigned portable
package excludes browser binaries, Streamlit and OpenAI. Dynamic resumes
require the separate builder and an explicit external Python interpreter.
The release manifest records the exact source commit and every bundled file
hash. Earlier releases, private inputs and installed applications are retained.
