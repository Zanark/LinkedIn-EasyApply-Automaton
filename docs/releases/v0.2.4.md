# Easy Apply Automaton v0.2.4

The desktop's action tile now has original, detailed multicolor artwork for
all 29 operation stages and seven command-lifecycle states. Outlines, internal
details and partial fills replace flattened stock icons; stages differ by
shape, not just color. Blue signals normal work, green/teal resume or completion
work, yellow pause/caution and red error/discard.

The redundant **CURRENT ACTION** header is removed. The icon and action name
are centered with padding, and the name is 23% smaller in the softer, rounded
Nunito font. A steady, soft border glow matches each stage's semantic color,
without flashing or pulsing. Only action names change font; the bundled font
retains its SIL Open Font License 1.1, included with the download.
Both themes and compact windows retain the live counters and last-selected
application-resume filename.
An operation or selected filename is not proof of attachment or submission.

The README screenshots and run walkthrough are refreshed from actual owned
widgets using fictional offline data. The walkthrough demonstrates changing
stages and retained resume selections without executing an automation command.

## Also included since v0.2.3

- Optional **Connect without a note if unavailable**, off by default. It still
  prefers a note and only permits an explicit note-free invitation action when
  note entry is unavailable. Dry run sends neither invitation type. Invitation
  delivery and note delivery remain separate.
- The project's seafoam form-and-lightning application icon for Windows windows,
  taskbar identity and both executables. Existing pinned shortcuts can retain
  their old icon; pin the updated executable instead.

## Download and upgrade

Download `EasyApplyAutomaton-0.2.4-windows-x64.zip`, verify `SHA256SUMS`, and
extract the entire folder into a new version directory. Keep `lea.exe` and
`_internal` beside `EasyApplyAutomaton.exe`. Finish active commands and save
editor changes before reopening; do not overwrite or restart a running app.

Existing workspace files and settings are retained. Set `LEA_WORKSPACE` to an
already configured workspace rather than initializing it again. An existing
`private-setup\Start-SourceSetup.cmd` runs its source checkout, not a downloaded
release; it needs the qualified source update and a deliberate new launch.
Updating a release does not replace an already-running source window.

Python is bundled; installed Edge/Chrome is required. The unsigned portable
package excludes browser binaries, Streamlit and OpenAI. Dynamic resumes need
the separate builder and an explicit external Python interpreter. Dashboard
features remain source extras.

The manifest records the exact source commit and every bundled file hash.
Offline qualification does not imply fresh-machine, live LinkedIn or human
visual acceptance. Earlier releases, private inputs and installed applications
are not replaced.
