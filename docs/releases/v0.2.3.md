# Easy Apply Automaton v0.2.3

The Windows desktop adds a **Current action** icon and operation name beside
the live counters, plus the final application-resume filename beside the Run
buttons. The filename survives scans, tools and finished runs until another
application selects a different resume. Selection alone is not proof of upload
or submission; confirmed outcomes remain separate.

The README screenshots and both walkthrough GIFs are refreshed from owned
widgets using fictional offline data. The run walkthrough shows an input pause,
a replacement tailored resume and retention during later actions. No command,
browser or application is executed to produce these previews.

## Dashboard source updates

The source dashboard includes all completed usability updates:

- Working report previews and original-byte downloads.
- Content-based default column widths across tables and editors.
- Explicit **Answer to save** beside **Save this answer**, with read-only comparisons.
- Application dates and a red oldest-first queue for untouched applications more than seven days old.
- Red **Overdue outreach** collapsed contact headings.
- Clickable skip-reason bars with complete event lists, saved posting details and filtered CSVs.
  Future skips preserve available decision-time context; missing historical data is labeled honestly.

The Streamlit dashboard and AI remain **source extras**, not part of the Windows
ZIP. The portable GUI and CLI include the native operation/resume indicators,
existing counters, colored logs, two-line hover help, fixed toolbar and offline
21-topic tutorial.

## Download and upgrade

Download `EasyApplyAutomaton-0.2.3-windows-x64.zip`, verify `SHA256SUMS`, and
extract the entire folder into a new version directory. Keep `lea.exe` and
`_internal` beside `EasyApplyAutomaton.exe`. Finish active commands and save
editor changes before reopening; do not overwrite or restart a running app.

Existing workspace files and settings are retained. Set `LEA_WORKSPACE` to an
already configured workspace rather than initializing it again. An existing
`private-setup\Start-SourceSetup.cmd` still runs the source checkout directly;
it does not download or choose a release. Updating this checkout and deliberately
reopening that launcher uses the current source, including its installed extras.

Python is bundled; installed Edge/Chrome is required. The unsigned portable
package excludes browser binaries, Streamlit and OpenAI. Dynamic resumes need
the separate builder and an explicit external Python interpreter.

The manifest records the exact source commit and every bundled file hash.
Offline qualification does not imply fresh-machine, live LinkedIn or human
visual acceptance. Earlier releases, private inputs and running apps are not replaced.
