# Public project handoff

This is a reviewed **public engineering projection** for contributors and coding
assistants. It is not the complete private continuity store, a conversation
archive, or a grant of authority to operate an account or publish changes.

| File | Purpose |
| --- | --- |
| [STATE.md](STATE.md) | Delivered source features, open boundaries and next steps |
| [MEMORY.md](MEMORY.md) | Durable architecture, safety and contributor invariants |
| [JOURNAL.md](JOURNAL.md) | Curated project milestones, not private session history |

Start with [the contributor contract](../../AGENTS.md), [developer guide](../../docs/developer_guide.md)
and [workstream index](../../todo/00_INDEX.todo). Verify current source and tracking
before resuming work; this handoff never overrides those sources.

## Publication boundary

Only these four files are Git-allowlisted. Private root continuity, social
history, applicant inputs, credentials, browser profiles and runtime artifacts
remain excluded. Unrecognized files in this directory stay ignored.

Write public notes independently from reviewed product behavior and public
evidence. Do not copy raw conversations or private stores and assume that
renaming or redacting fields makes the result safe. Review each proposed update
and stage explicit paths; never force-add the context directory.
